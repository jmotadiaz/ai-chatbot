# Diseño: GLM 5.2 (OpenCode Go) como modelo userInvocable

## Contexto y Objetivo

Añadir el modelo **GLM 5.2** de Z.AI (`company: "zai"`) como modelo `userInvocable: true` servido a través del provider **OpenCode Go** (`provider: { kind: "opencodeGo", modelId: "glm-5.2" }`).

Al ser `userInvocable: true`, el modelo estará disponible tanto en el chat de la aplicación como en el selector de modelos del coding agent.

## Especificaciones del Modelo (OpenCode Go)

- **Display ID / Name:** `"GLM 5.2"`
- **Provider Kind:** `"opencodeGo"`
- **Provider Model ID:** `"glm-5.2"`
- **Company:** `"zai"`
- **Reasoning:** `true`
- **Context Window:** `1_000_000` tokens
- **Max Output Tokens:** `128_000` tokens
- **Costos (por millón de tokens):**
  - Input: `$1.40` (`1.4`)
  - Output: `$4.40` (`4.4`)
  - Cache Read: `$0.26` (`0.26`)
  - Cache Write: `$0` (`0`)
- **Parámetros de muestreo:** `temperature: 0.6`, `topP: 0.95`
- **Reasoning / Thinking:**
  - `defaultThinkingLevel`: `"high"`
