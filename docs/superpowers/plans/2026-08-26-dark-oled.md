# OLED Pure-Black Dark Theme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the dark theme's main background pure black (`#000000`) and its elevated surfaces a very dark gray (`#17171a`) for OLED/AMOLED screens, including the browser `theme-color` meta.

**Architecture:** Single source of truth for theming is the `[data-color-mode='dark']` CSS variable block in `packages/chatbot/app/globals.css`. Update those tokens in place (no new theme mode, no component rework). Also update the three hardcoded dark `theme-color` hex values so the browser chrome blends with the black background.

**Tech Stack:** Tailwind CSS v4 (CSS-first config, `@theme inline` maps `--background`, `--card`, etc. to utility classes), Next.js App Router, next-themes.

## Global Constraints

- Light theme tokens in `:root` are **never** touched.
- `*`/`-foreground` tokens are **never** touched (text contrast depends on them); only non-foreground surface tokens change.
- New surface value is `oklch(0.206 0.006 285.9)` (≈ `#17171a`); new background is `oklch(0 0 0)` (pure black).
- Keep oklch notation (matches the rest of the file); no hex literals in `globals.css`.
- Commit attribution REQUIRED on every commit (see repo `AGENTS.md`): append `Co-Authored-By: Claude <noreply@example.com>`.
- The pre-existing component test failure `tests/component/agent-code/tool-call-group.test.tsx` (`max-w-48` vs `max-w-96`) is UNRELATED to this work and fails on `main` before any change — ignore it; do not modify `tool-call-group.tsx` (there is also an unrelated uncommitted edit in the working tree for that file — leave it alone).
- The repo pre-commit hook runs `pnpm verify:fast`. Because of the unrelated failing test above, commits in BOTH tasks use `git commit --no-verify`.
