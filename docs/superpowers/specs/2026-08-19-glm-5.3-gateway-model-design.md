# Diseño: GLM 5.3 (Vercel AI Gateway) como modelo userInvocable

## Contexto y Objetivo

Añadir el modelo **GLM 5.3** de Z.AI (`company: "zai"`) como modelo `userInvocable: true` servido a través de **Vercel AI Gateway** (`provider: { kind: "gateway", modelId: "zai/glm-5.3" }`).

Al ser `userInvocable: true`, el modelo estará disponible tanto en el chat de la aplicación como en el selector de modelos del coding agent.

## Especificaciones del Modelo (Vercel AI Gateway)

Basado en la ficha técnica oficial en Vercel AI Gateway (`https://vercel.com/ai-gateway/models/glm-5.3`):
- **Display ID / Name:** `"GLM 5.3"`
- **Provider Kind:** `"gateway"`
- **Provider Model ID:** `"zai/glm-5.3"`
- **Company:** `"zai"`
- **Reasoning:** `true`
- **Context Window:** `1_000_000` tokens (1M)
- **Max Output Tokens:** `12_800` tokens (~13K)
- **Costos (por millón de tokens):**
  - Input: `$1.40` (`1.4`)
  - Output: `$4.40` (`4.4`)
  - Cache Read: `$0.26` (`0.26`)
  - Cache Write: `$0` (`0`)
- **Parámetros de muestreo:** `temperature: 0.6`, `topP: 0.95`
- **Reasoning / Thinking:**
  - `defaultThinkingLevel`: `"high"`
  - `thinkingLevelMap`:
    ```ts
    {
      off: null,
      minimal: "minimal",
      low: "low",
      medium: "medium",
      high: "high",
      xhigh: "xhigh",
    }
    ```

## Arquitectura y Componentes Afectados

1. **`packages/models/src/catalog.ts`**
   - Registrar la entrada en `MODEL_CATALOG` dentro del bloque `userInvocable: true`.
2. **`packages/models/src/mapping.ts`**
   - Ya soporta `kind: "gateway"` mapeando a `"vercel-ai-gateway"` en Pi.
3. **`packages/models/src/generate-models-json.ts`**
   - Al ser un modelo `gateway` con `userInvocable: true`, genera automáticamente su definición en `providers["vercel-ai-gateway"].models` usando los límites y costes especificados.
4. **`packages/chatbot/lib/infrastructure/ai/providers.ts`**
   - Ya soporta `gateway: (modelId: string) => gateway(modelId)` de `@ai-sdk/gateway` / `ai`.
5. **Tests de Validación:**
   - `packages/models/src/catalog.test.ts`: Actualizar `INVOCABLE_MODEL_IDS` e invariantes.
   - `packages/models/src/mapping.test.ts`: Verificar mapeo bidireccional `toPiModelId` / `toChatModelId` para `GLM 5.3`.
   - `packages/models/src/generate-models-json.test.ts`: Verificar que `generateModelsJson` describe `GLM 5.3` completamente bajo `vercel-ai-gateway`.
   - `packages/chatbot/tests/unit/foundation-model/glm-5.3-config.test.ts`: Verificar configuración en chatbot.
